# Casos de Teste - SauceDemo

## Sobre o projeto

Este repositório contém a entrega do desafio **"Escrevendo Casos de Teste no Formato Passo a Passo"**, utilizando o site SauceDemo como sistema sob teste.

Foram elaborados casos de teste seguindo o formato **Step-by-Step**, contemplando cenários positivos e negativos.

## Objetivo

Praticar a elaboração de casos de teste claros, objetivos e reproduzíveis, utilizando técnicas de projeto de testes.

## Site utilizado

https://www.saucedemo.com

## Funcionalidades testadas

- Login
- Carrinho de Compras
- Ordenação de Produtos

## Técnicas de Design de Teste

Nos casos de Login foi utilizada a técnica de:

- Particionamento de Equivalência

## Estrutura dos Casos de Teste

Todos os casos seguem o padrão:

- ID
- Título
- Pré-condições
- Prioridade
- Passos
- Resultado Esperado
- Técnica utilizada (quando aplicável)
